### Description

```text
Definition:
*. As a system developer I need to identify the strip presence and each well location when assay analysis is requested from ICS, so that I can use this information for features detection
 
Acceptance Criteria:
*. The PRA software shall run the ROI extraction algorithm each time when the camera is prepared with a plate scan profile.
	*. Note: the ROI extraction algorithm is run on the color corrected image, which is the plate image as seen from above - the flipped image - ("<UID>_color_corrected")
	*. Note: The ROI extraction algorithm is independent of the requested feature / score calculation profiles - it only depends on the plate geometry, which is fixed (i.e. the plate image always includes up to 2 strips with 8 wells each)
*. The ROI extraction algorithm shall apply the following steps:
1. it shall identify all circles in the image (raw detection)
=> X and Y detection center are determined for each well (in pixels)
=> Detection radius in pixels and mm are determined for each well
2. It shall apply the known geometrical constraints of each strip (originated from the strip mechanical design), for the detected wells
=> X and Y ROI center are geometrically fitted for each well (in pixels)
=> ROI radius in pixels and mm for each well is a fixed parameter
3. It shall calculate the following differences between the detected and the geometrically fitted circles:
- the distance between the detected center (step 1) and the geometrically fitted center (step 2) for each detected well
=> Distance wrt detection in pixels and mm
         - the angle between the horizontal line and the line between the detected and geometrically fitted circle centers for each detected well
=> Angle wrt detection (degrees)
- the angle between the horizontal line and the line that unites the geometrically fitted centers of all detected wells from a strip (step 2)
=> Angle (degrees)
4. It shall calculate the mean squared error between detected well centers (step 1) and geometrically fitted well centers (step 2) across all detected wells from a strip, in pixels^2
=> Error wrt detection (pix^2)
5. It shall calculate the mean euclidian distance error between detected well centers (step 1) and geometrically fitted well centers (step 2) across all detected wells from a strip, in mm
=> Error wrt detection (mm)
*. The ROI extraction algorithm shall consider the following correspondence between the ROI index and well positions in the image as seen from above (this is the flipped image):
=> 1: top right (A1)
=> 8: top left (H1)
=> 9: bottom right (A2)
=> 16: bottom left (H2)
*. After running the ROI extraction algorithm on the "<UID>_color_corrected" image, the PRA software shall deliver the followings:
	*. well images - handled under separate user story.
	*. the '<UID>_ROIs.csv' and '<UID>_ROIs_properties.csv' result files shall be saved in the '<UID>/results' folder (content of the result files is handled under 2850793)
 
Out of Scope:
*. The creation of well cropped images shall be handled under separate user story
	*. image of each containing well shall be cropped and saved as "<UID>_color_<WellPosition>" in the '<UID>/images' folder.
	*. The well images are created only for the present strip(s). If a strip is missing, there will be no well images created for that strip => will be 0, 8 or 16 well images created.
Note: <WellPosition> is the carrier position of the well (A1, A2, etc)
*. The content of the result files created after running the ROIs extraction algorithm is handled under different u.s.: 2850793
```

Workflow
 
+ Preparation

- SSW initializes the reader module and camera.
+ Exposure and Flatfield calibration
- SSW ensures no target in optical path (open chamber).
The following has to be repeated for each ImageAcquisitionProfile if applicable:
- SSW calls PrepareCamera with FlatfieldProfile and ImageAcquisitionProfile => Plate Reader Application (PRA) configures the camera according to the camera and acquisition profile.
- SSW calls ExecuteCalibration => PRA acquires images and creates the necessary calibration data.
1) Exposure Calibration
PRA performs the exposure calibration with a configurable target gray value (default: 220) and stores the outcome to the image acquisition configuration file (calibration_config.json).
2) Flatfield Calibration
PRA performs the flatfield calibration using the exposure times determined in exposure calibration and stores the outcome as flatfield image (flatfield.bmp) and flatfield configuration file (flatfield_config.json).
+ Color Calibration
- SSW reads the color calibration target barcode [CCTBarcode] (contains expiration and serial number) and loads it into the optical path.
** see note below (- SSW transfers the matching color reference file onto the imaging board (Path: /home/root/calibration/**) and PRA copies the ref file with matching barcode with the loaded CCT*** into /home/root/calibration/new). The file name of the reference color file shall contain the barcode of the target. File name shall be RefPlate_<Barcode> e.g.: RefPlate_231100000042.csv (Format of BC TBD - start with YYMMSSSSSSSS)) see note below**

=> PRA uses the matching reference color file for color calibration
